# AI Image Studio

## Setup
```bash
pip install -r requirements.txt
cp .env.example .env
# Add your HF_API_KEY from huggingface.co/settings/tokens
python app.py
```

## Free API Keys
1. **Hugging Face** (Best quality) — huggingface.co/settings/tokens → New token (read)
2. **Stable Horde** (No key needed) — stablehorde.net for account
